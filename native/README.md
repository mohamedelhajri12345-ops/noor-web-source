# NOOR Native 🌙

هذه هي طبقة Native الجديدة لمشروع NOOR. الواجهة مبنية بـ React Native + Expo وليست WebView.

## المرحلة الحالية
- Native bottom navigation.
- واجهة عربية RTL.
- الرئيسية.
- القرآن + قارئ أولي.
- الأذكار.
- المسبحة مع Haptics.
- الألعاب الإسلامية.
- شاشة المزيد.
- Android package: com.elhajri.noor.
- iOS bundle identifier: com.elhajri.noor.

## المرحلة التالية
نقل بقية الوحدات وربط المصادقة، المجتمع، الصوت، الإشعارات، مواقيت الصلاة، القبلة والتنزيلات بالخدمات الأصلية المناسبة لـReact Native.
